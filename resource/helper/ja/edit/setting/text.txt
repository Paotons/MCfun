[title]ハイライト[/title]

編集時、対応する要素のハイライト色を自分で設定できます。

[title]補完[/title]

[b]最大補完数：[/b]このしきい値を超えた補完項目は、負荷を軽減するため削除されます。

[b]ヒントワードを表示：[/b]有効にすると、ヒントワードが括弧付きで表示されます。例：
[code]cat   (ネコ)[/code]

[b]ヒントワードで重み付け：[/b]有効にすると、入力したヒントワードが優先的に上位に表示されます。ヒントワードの類似度を計算するため、パフォーマンス消費が倍になります。

[b]名前空間名を補完：[/b]無効にすると、[code]minecraft:apple[/code] のようなものがすべて [code]apple[/code] のみ表示されます。有効にすると若干のパフォーマンス計算が発生します。
[title]動作[/title]

[b]ダブルタップマッピング：[/b]これは記号入力の補助です。同じ文字を素早く連続入力すると、変換されます。デフォルト設定は以下の通りです：
[code]" " : "\t"
"s" : "§"
"." : "~"
"," : "^"
"z" : "="
"n" : "!"
"a" : "@"
"q" : "{"
"p" : "}"
"w" : "["
"o" : "]"
"e" : "<"
"i" : ">"[/code]

[title]自動保存[/title]

[b]自動保存：[/b]有効にすると自動保存が許可されます。

[b]保存間隔：[/b]自動保存の時間間隔。

[title]文法[/title]

デフォルトのエディタにおける文法。

[b]文法パス：[/b]文法のパスを確認できます。起動時にディレクトリがない場合、コピーを試みます。
[b]文法を抽出：[/b]文法が失われた、または更新されていない場合、手動で更新できます。
