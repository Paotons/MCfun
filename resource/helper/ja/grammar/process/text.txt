[title]説明[/title]

エディタにコマンドの要素がどう組み合わされるかを伝えるために使います。要素 [file grammar/element]文法>>要素[/file] を参照。

各要素は以下の新しいメンバーを含められます：
[b]id:[/b] 非負整数。ID。空の場合はランダムな数値になります。重複または負の数はクラッシュの可能性があるので、絶対に重複させないでください。
[b]extends:[/b] 整数。継承元。直前に成功した要素の ID です。-2 は任意、-1 は最先頭を表します。空の場合は -2。
[b]goto:[/b] 整数。選択肢の場合は整数配列。成功時にジャンプする ID で、選択肢の場合は付加データに応じて対応するジャンプを行います。空の場合はそのまま次のステップを実行します。
[b]is_end:[/b] ブール。終了フラグ。空でなければ成功時に変更を試みます。終了後も [code]false[/code] の場合はエラーになります。

また、行が [code]{"type" : "file", "file" : "path"}[/code] を使用して他のファイルの内容をデータとして読み込むことを許可します。例：[code]"give" : {"type" : "file", "file" : "proces/give.json"}[/code]

[title]V1[/title]

[code] "give" : [{...}, {...}][/code]

これで [code]give[/code] コマンドが定義されますが、ヒントワードはありません。

[title]V2[/title]

[code]"give" : {
	"descriotion" : "プレイヤーにアイテムを与える",
	"data" : [
		{...},
		{...}
	]
}
[/code]

[b]description:[/b] 説明。ヒントワード。
[b]data:[/b] データ。

これで [code]give[/code] コマンドが定義され、ヒントワードが付きます。
