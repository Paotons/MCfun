[title]描述[/title]

用於表示列表 [file grammar/entry]語法>>列表[/file] 中的元素，開始用來定義各種字符串。

[title]V1[/title]

例如 [code]gamemode[/code] 可表示為：
[code]{
	"type" : "string",
	"data" : [
		"a",
		"c",
		"s"
	]
}[/code]

這樣就可以表示 [code]gramemode[/code] 有 [code]a,c,s[/code] 三個模式了。

[code]data:[/code] 用於定義各種字符串。

[title]V2[/title]

例如 [code]gamemode[/code] 可表示為：
[code]{
	"type" : "string",
	"data" : {
		"a" : "冒險模式",
		"c" : "創造模式",
		"s" : "生存模式"
	}
}[/code]

這樣就可以表示 [code]gramemode[/code] 有 [code]a,c,s[/code] 三個模式了，並且伴隨著對應的提示詞。
