[title]高亮[/title]

編輯時，對應元素高亮的顏色，可以自己設置。

[title]補全[/title]

[b]最大補全數量：[/b]超過該閾值後面的補全項會被砍掉，以減少開銷。

[b]顯示提示詞：[/b]開啟後提示詞會以括號的方式顯示。如：
[code]cat   (貓)[/code]

[b]使用提示詞加權：[/b]開啟後，輸入提示詞能優先排在前面。由於要計算提示詞的相似度，性能消耗翻倍。

[b]補全空間名稱：[/b]關閉後，所有類似 [code]minecraft:apple[/code] 只顯示 [code]apple[/code] 開啟會帶來少量的性能計算。
[title]行為[/title]

[b]雙擊映射：[/b]這是幫助符號的輸入，如果你連續快速輸入同一字符，就會進行轉化。默認配置是如下：
[code]" " : "\t"
"s" : "§"
"." : "~"
"," : "^"
"z" : "="
"n" : "!"
"a" : "@"
"q" : "{"
"p" : "}"
"w" : "["
"o" : "]"
"e" : "<"
"i" : ">"[/code]

[title]自動保存[/title]

[b]自動保存：[/b]開啟後允許自動保存。

[b]保存間隔：[/b]自動保存的時間間隔。

[title]語法[/title]

默認編輯器中的語法。

[b]語法路徑：[/b]你可以查看語法的路徑，每次啟動時如果檢測到沒有目錄，會嘗試複製進去。
[b]提取語法：[/b]如果語法丟失或者是沒有更新，可以手動更新。
