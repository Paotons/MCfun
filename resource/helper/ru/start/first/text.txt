[title]Создание проекта[/title]

Войдите в список проектов и нажмите [code]Новый[/code] на верхней панели инструментов.
Введите имя проекта; рекомендуется использовать английское название.
Каталог проекта можно оставить по умолчанию.

После создания выберите проект и нажмите [code]Редактор[/code] справа или щёлкните по проекту ещё раз, чтобы войти в редактор.

[title]Создание файла[/title]

Нажмите [code]Файл>>Система[/code] на верхней панели инструментов, чтобы войти в файловую систему.
В файловой системе найдите сверху [code]Добавить>>mcfun[/code], введите имя файла (например, [code]Welcome[/code]) и подтвердите.

Затем выберите файл и нажмите рядом [code]Открыть>>Файл[/code], чтобы открыть файл.

[title]Редактирование файла[/title]

После открытия файл автоматически выделяется.
Можно для начала ввести [code]give @s app[/code], затем нажать [code]Enter/перенос строки[/code] для быстрого автодополнения.
Так мы получаем строку команды [code]give @s minecraft:apple[/code].

Затем нажмите [code]Файл>>Сохранить[/code] на верхней панели инструментов, иначе файл может быть потерян.

[title]Настройки проекта[/title]

Если у вас самая свежая версия Minecraft, настройки можно не трогать и сразу переходить к экспорту.

[code]Проект>>Настройки[/code] на верхней панели открывает настройки проекта.
[code]Имя проекта:[/code] название этого проекта.
[code]Путь проекта:[/code] путь этого проекта. Не редактируется, служит только для копирования.
[code]Версия проекта:[/code] версия, отображаемая после экспорта. По умолчанию 1.0.0.
[code]Описание проекта:[/code] отображается в описании набора ресурсов после экспорта.
[code]Минимальная версия игры:[/code] версия Minecraft, в которой работает этот набор ресурсов. По умолчанию 1.20.0.
[b]Внимание:[/b]если набор ресурсов не отображается, скорее всего, неверно настроена [code]минимальная версия игры[/code].

[title]Экспорт проекта[/title]

Нажмите [code]Проект>>Экспорт[/code] на верхней панели инструментов, чтобы открыть окно экспорта.
Можно настроить путь экспорта или оставить значение по умолчанию.
Нажмите «Экспорт» и подождите.
По завершении можно скопировать путь, чтобы найти архив, или сразу открыть его.

[b]Внимание:[/b]если изначально не был выбран каталог данных, по умолчанию используется каталог приложения, к которому может не быть прямого доступа. Перейдите в [code](Редактор) Настройки>>Интерфейс>>Общие>>каталог данных[/code], чтобы изменить его.
[b]Внимание:[/b]во время экспорта окно нельзя закрыть.

[title]Импорт в игру[/title]

Найдите свою карту; обычно она находится в каталоге [code]/storage/emulated/0/Android/data/com.mojang.minecraftpe/files/games/com.mojang/minecraftWorlds/[/code]. Определить название карты можно по скриншоту внутри или по файлу [code]levelname.txt[/code].
Распакуйте архив в каталог [code]behavior_packs[/code] — на этом всё готово.

[b]Внимание:[/b]наборы поведения NetEase могут находиться внутри приложения и быть недоступны напрямую. Нужно вручную скопировать их в командный блок; [file tool/coper]Помощник копирования[/file] поможет быстро скопировать команды из функции.

[title]Активация набора поведения[/title]

Войдите в Minecraft, откройте экран редактирования мира и в разделе [code]Наборы поведения>>Мои наборы[/code] вы должны увидеть пункт со значком ошибки. Нажмите и активируйте его.

[b]Внимание:[/b]если он не отображается, возможно, нужно перезайти в игру, либо неверно настроена [code]Настройки проекта>>Минимальная версия игры[/code].

[title]Вызов функции[/title]

Войдите в мир и введите [code]/function Welcome/ имя_вашего_файла[/code] — вы получите яблоко.

[b]Внимание:[/b]если написано, что функции не существует, возможно, нужно выполнить [code]/reload[/code], чтобы перезагрузить функции.
