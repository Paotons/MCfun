[title]Описание[/title]

Список — это список данных автодополнения внутри команды, который динамически изменяется вместе с командой.

[title]Добавление[/title]

[code]@list <имя_списка> add <элемент_автодополнения>[/code]

[b]Имя списка:[/b] список, с которым выполняется действие.
[b]Элемент автодополнения:[/b] элемент, который нужно добавить.

Например: [code]@list tag add my_tag[/code] — так при последующем автодополнении Tag появится вариант my_tag.
