[title]Подсветка[/title]

При редактировании цвет подсветки соответствующих элементов можно настроить самостоятельно.

[title]Автодополнение[/title]

[b]Максимум вариантов автодополнения:[/b]варианты сверх этого порога отбрасываются для снижения затрат.

[b]Показывать подсказки:[/b]при включении подсказки отображаются в скобках. Например:
[code]cat   (Кошка)[/code]

[b]Использовать вес подсказок:[/b]при включении введённые подсказки получают приоритет. Поскольку требуется вычислять схожесть подсказок, нагрузка удваивается.

[b]Дополнять имена пространств:[/b]при выключении всё вида [code]minecraft:apple[/code] отображается только как [code]apple[/code]; включение добавляет небольшую нагрузку.
[title]Поведение[/title]

[b]Двойное нажатие:[/b]это помогает вводить символы: если быстро ввести один и тот же символ дважды, он будет преобразован. По умолчанию настроено так:
[code]" " : "\t"
"s" : "§"
"." : "~"
"," : "^"
"z" : "="
"n" : "!"
"a" : "@"
"q" : "{"
"p" : "}"
"w" : "["
"o" : "]"
"e" : "<"
"i" : ">"[/code]

[title]Автосохранение[/title]

[b]Автосохранение:[/b]при включении разрешает автосохранение.

[b]Интервал сохранения:[/b]промежуток времени между автосохранениями.

[title]Грамматика[/title]

Грамматика, используемая редактором по умолчанию.

[b]Путь грамматики:[/b]вы можете посмотреть путь грамматики; при каждом запуске, если каталог отсутствует, будет предпринята попытка скопировать его.
[b]Извлечь грамматику:[/b]если грамматика потеряна или устарела, её можно обновить вручную.
