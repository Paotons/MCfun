[title]Описание[/title]

Используется для представления элементов списка [file grammar/entry]Грамматика>>Список[/file]; изначально служит для определения различных строк.

[title]V1[/title]

Например, [code]gamemode[/code] можно записать так:
[code]{
	"type" : "string",
	"data" : [
		"a",
		"c",
		"s"
	]
}[/code]

Так [code]gamemode[/code] получает три режима: [code]a, c, s[/code].

[code]data:[/code] используется для определения различных строк.

[title]V2[/title]

Например, [code]gamemode[/code] можно записать так:
[code]{
	"type" : "string",
	"data" : {
		"a" : "Режим приключения",
		"c" : "Режим творчества",
		"s" : "Режим выживания"
	}
}[/code]

Так [code]gamemode[/code] получает три режима: [code]a, c, s[/code] вместе с соответствующими подсказками.
