[title]Описание[/title]

Сообщает редактору, как должны комбинироваться элементы команды. См. элемент [file grammar/element]Грамматика>>Элемент[/file]

Каждый элемент может содержать новые члены:
[b]id:[/b] неотрицательное целое. ID; если пусто, берётся случайное число. Повторы или отрицательные значения могут привести к сбою — не повторяйте их.
[b]extends:[/b] целое, родитель. ID последнего успешно выполненного элемента. -2 означает любой, -1 — самое начало. Пусто равносильно -2.
[b]goto:[/b] целое или массив целых для параметров. ID, к которому осуществляется переход при успехе; если это параметр, переход зависит от дополнительных данных. Пусто означает переход к следующему шагу.
[b]is_end:[/b] логическое, признак завершения. Если не пусто, при успехе значение будет изменено. Если команда завершилась, а значение осталось [code]false[/code], возникнет ошибка.

Строка может использовать [code]{"type" : "file", "file" : "path"}[/code] для загрузки содержимого другого файла в качестве данных. Например: [code]"give" : {"type" : "file", "file" : "proces/give.json"}[/code]

[title]V1[/title]

[code] "give" : [{...}, {...}][/code]

Так задаётся команда [code]give[/code], но без подсказок.

[title]V2[/title]

[code]"give" : {
	"descriotion" : "Выдать предмет игроку",
	"data" : [
		{...},
		{...}
	]
}
[/code]

[b]description:[/b] описание, подсказка.
[b]data:[/b] данные.

Так задаётся команда [code]give[/code] вместе с подсказками.
