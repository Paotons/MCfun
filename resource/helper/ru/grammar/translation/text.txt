[title]Описание[/title]

Служит для определения переводов грамматики.

[title]Состав[/title]

[code]{
	"zh" : {...}
}[/code]

Ключ — имя языка, значение — данные языка. Данные языка бывают двух типов.

[title]Данные языка 1[/title]

[code]{
	"apple" : "Яблоко",
	"stone" : "Камень"
}[/code]

Первый тип — это таблица отображения. Заменяет встречающиеся коды на соответствующие значения.
Конечно, таблица переводов может быть очень большой; её можно заменить на [code]{"type" : "file", "file" : path}[/code].

[title]Данные языка 2[/title]

[code]{
	"type" : "po_file",
	"file" : path
}[/code]

Второй тип — это po-файл. Выбирается po-файл для отображения.
