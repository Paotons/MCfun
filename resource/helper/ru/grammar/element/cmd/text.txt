[title]Описание[/title]

Продвинутое использование элемента — массив строк внутри элемента. На данный момент полностью не разработано, часть функций пока имеет проблемы.

[title]Список[/title]

У каждой команды есть список. С помощью [code]list[/code] можно управлять этим списком.

[code]list <имя_списка> add self[/code] добавляет строку текущего элемента в список.

[title]Автодополнение[/title]

Управляет автодополнением. С помощью [code]completion[/code] можно управлять автодополнением.

[code]completion list <имя_списка>[/code] показывает меню автодополнения списка.

[b]Внимание:[/b]эта функция не завершена; сейчас поддерживаются только [code]string, word, selector[/code]

[title]Список ожиданий[/title]

Управляет списком ожиданий, который также влияет на автодополнение. С помощью [code]expectation[/code] можно управлять автодополнением.
При каждом запуске, если в элементе возникает ошибка, он автоматически добавляется в список ожиданий.

[code]expectation clear[/code] очищает список ожиданий.

[b]Внимание:[/b]эта функция не завершена; сейчас поддерживается только [code]null[/code]
