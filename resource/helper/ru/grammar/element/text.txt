[title]Описание[/title]

Команду можно разбить на различные элементы.

Например:
[code]execute as @a run give @s minecraft:apple 64[/code]
можно разбить так:
[b]execute:[/b] заголовок команды.
[b]as:[/b] параметр.
[b]@a:[/b] селектор.
[b]run:[/b] параметр.
[b]give @s minecraft:apple 64:[/b] подкоманда, которую, разумеется, тоже можно разбить.

[title]Типы[/title]

Сейчас элементы поддерживают несколько типов.

[b]null:[/b] без типа, обозначает заполнитель.
[b]bool:[/b] логический тип, представляет два варианта [code]false[/code] и [code]true[/code].
[b]int:[/b] целочисленный тип, представляет числа вроде [code]64[/code].
[b]float:[/b] тип с плавающей точкой, представляет числа с десятичной точкой вроде [code]0.5[/code].
[b]option:[/b] параметр, обычно это несколько фиксированных вариантов.
[b]rich_string:[/b] расширенный текст, поддерживает отображение [code]§[/code].
[b]word:[/b] слово, поддерживает только символы разных языков, дефисы и цифры; обычно обозначает имя игрока.
[b]string:[/b] строка, поддерживает всё, что не разделено пробелами или отступами.
[b]spaceitem:[/b] пространственный предмет; иногда записывается как [code]space_item[/code]; может обозначать [code]apple[/code] или [code]minecraft:apple[/code]
[b]point_path:[/b] точечный путь, может обозначать [code]mob.cat[/code]
[b]file_path:[/b] путь к файлу, может обозначать [code]main/myfun.mcfunction[/code]
[b]coord:[/b] координата, есть три формы записи: [code]5, ~5, ^5[/code], поддерживает числа с плавающей точкой.
[b]coords:[/b] несколько координат, часто используется для обозначения позиции; может обозначать [code]~~~[/code] или [code]^^^3[/code] и другие координаты.
[b]selector:[/b] селектор, может обозначать [code]@e\[type=player\][/code], а также более сложные выборки; поддерживает имена игроков.
[b]array:[/b] подобно массиву, заключается в квадратные скобки; это тело селектора.
[b]dictionary:[/b] подобно словарю, заключается в фигурные скобки.
[b]command:[/b] команда — целая команда.

[title]Структура данных[/title]

Данные — это набор данных, описывающий каждый элемент. Есть [code]type, detail, items, description, cmd, custom[/code]
Например: [code]{"type" : "int", "description" : "Счёт"}[/code]
Это данные элемента типа int, распознающие [code]1, 0, 100, -1[/code]

[b]type:[/b] тип, обозначает тип элемента, по умолчанию [code]null[/code]
[b]detail:[/b] детали, используются для ограничения элемента или задания его диапазона; у разных типов свои условия.
[b]items:[/b] дополнительные данные, обычно подданные элемента; часто используется для вариантов [code]option[/code].
[b]description:[/b] описание, используется для подсказки, по умолчанию Unknow
[b]cmd:[/b] команды, для продвинутого использования; могут управлять редактором. См. [file grammar/element/cmd]Команды[/file]
[b]custom:[/b] пользовательские данные, пока не имеют применения.
