[title]프로젝트 만들기[/title]

프로젝트 목록에 들어가 상단 도구 모음의 [code]새로 만들기[/code] 를 클릭합니다.
프로젝트 이름을 입력합니다. 영어로 이름 짓는 것을 권장합니다.
프로젝트 디렉터리는 기본값을 선택해도 됩니다.

생성에 성공하면, 프로젝트를 선택하고 오른쪽의 [code]편집[/code] 을 클릭하거나, 프로젝트를 다시 클릭해 편집 목록으로 들어갑니다.

[title]파일 만들기[/title]

상단 도구 모음의 [code]파일>>시스템[/code] 을 클릭해 파일 시스템으로 들어갑니다.
파일 시스템에서 상단의 [code]추가>>mcfun[/code] 을 찾아 파일 이름을 입력합니다. 여기서는 [code]Welcome[/code] 을 사용하고 확인합니다.

그런 다음 파일을 선택하고 옆의 [code]열기>>파일[/code] 을 클릭해 파일을 엽니다.

[title]파일 편집[/title]

파일을 열면 파일이 자동으로 선택됩니다.
먼저 [code]give @s app[/code] 를 입력해 볼 수 있습니다. 이때 [code]Enter/줄바꿈[/code] 을 한 번 누르면 빠르게 자동 완성됩니다.
이제 [code]give @s minecraft:apple[/code] 한 줄의 명령어를 편집한 것입니다.

그런 다음 위쪽 도구 모음의 [code]파일>>저장[/code] 을 클릭합니다. 그렇지 않으면 파일이 유실될 수 있습니다.

[title]프로젝트 설정[/title]

최신 버전 Minecraft라면 설정하지 않고 바로 내보내도 됩니다.

위쪽 도구 모음의 [code]프로젝트>>설정[/code] 으로 프로젝트 설정을 열 수 있습니다.
[code]프로젝트 이름:[/code] 이 프로젝트의 이름.
[code]프로젝트 경로:[/code] 이 프로젝트의 경로. 편집할 수 없으며, 복사용으로만 사용됩니다.
[code]프로젝트 버전:[/code] 내보낸 후 표시할 버전. 기본값 1.0.0.
[code]프로젝트 설명:[/code] 내보낸 후 리소스 팩 설명에 표시됩니다.
[code]최소 게임 버전:[/code] 이 리소스 팩이 실행되는 Minecraft 버전. 기본값 1.20.0.
[b]주의:[/b] 리소스 팩에 표시되지 않는다면, 십중팔구 [code]최소 게임 버전[/code] 설정이 잘못된 것입니다.

[title]프로젝트 내보내기[/title]

위쪽 도구 모음에서 [code]프로젝트>>내보내기[/code] 를 클릭해 내보내기 창을 엽니다.
내보내기 경로를 설정할 수 있으며, 물론 기본값도 괜찮습니다.
내보내기를 클릭하고 기다립니다.
내보내기가 끝나면 경로를 복사해 압축 파일을 찾거나, 바로 열어 위치를 확인할 수 있습니다.

[b]주의:[/b] 처음에 데이터 디렉터리를 설정하지 않았다면, 기본적으로 소프트웨어 디렉터리를 사용하게 되어 직접 접근하지 못할 수 있습니다. [code](편집기) 설정>>인터페이스>>일반>>데이터 디렉터리[/code] 에서 변경해야 합니다.
[b]주의:[/b] 내보내기 과정 중에는 창을 닫을 수 없습니다.

[title]게임에 가져오기[/title]

자신의 맵을 찾습니다. 일반적으로 [code]/storage/emulated/0/Android/data/com.mojang.minecraftpe/files/games/com.mojang/minecraftWorlds/[/code] 디렉터리에 있습니다. 안의 스크린샷이나 [code]levelname.txt[/code] 를 보고 맵 이름을 판단할 수 있습니다.
맵을 찾았으면 압축 파일을 [code]behavior_packs[/code] 디렉터리에 풀면 성공입니다.

[b]주의:[/b] 넷이즈(NetEase) 행동 팩은 소프트웨어 내부에 있을 수 있어 사용할 수 없습니다. 명령 블록에 수동으로 복사해야 하며, [file tool/coper]복사 도우미[/file] 가 함수의 명령어를 빠르게 복사하는 데 도움이 됩니다.

[title]행동 팩 활성화[/title]

Minecraft에 들어가 월드 편집 화면에서 [code]행동 팩>>내 팩[/code] 에 오류 아이콘이 있는 항목이 있어야 합니다. 클릭하여 활성화합니다.

[b]주의:[/b] 표시되지 않는다면, 게임을 다시 들어가야 하거나 [code]프로젝트 설정>>최소 게임 버전[/code] 설정이 잘못된 것일 수 있습니다.

[title]함수 호출[/title]

월드에 들어가 [code]/function Welcome/ 파일 이름[/code] 를 입력하면 사과 하나를 얻게 됩니다.

[b]주의:[/b] 함수가 없다고 표시되면 [code]/reload[/code] 로 함수를 다시 불러와야 할 수 있습니다.
