[title]개요[/title]

인터페이스 왼쪽 상단에는 다양한 기능 블록이 있으며, 각각 펼칠 수 있어 더 많은 기능이 있습니다. 구체적인 내용은 다음과 같습니다.

프로젝트 >> 설정, 내보내기, 다시 로드, 종료
파일 >> 저장, 모두 저장, 실행 취소, 다시 실행, 열기, 닫기, 모두 닫기
편집 >> 실행 취소, 다시 실행, 복사, 잘라내기, 붙여넣기, 모두 선택, 줄 선택, 자동 완성, 자동 완성 취소

인터페이스 오른쪽 상단은 다른 기능 모듈로, 도움말, 설정이 있습니다.

왼쪽은 파일 리스트로, 클릭하면 파일을 전환할 수 있습니다. 열기와 닫기는 지원하지만 이동 기능은 아직 구현되지 않았습니다. 아쉽네요.
아래쪽은 표시 영역으로, 오류 안내를 표시하고 클릭하여 펼칠 수 있으며, 오른쪽에는 커서 위치가 표시됩니다.

가운데는 텍스트 편집기이며, 오른쪽 미니맵으로 스크롤을 대체할 수 있습니다. 관련 설정은 아직 추가되지 않았습니다.
