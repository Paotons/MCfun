[title]하이라이트[/title]

편집 시 해당 요소의 하이라이트 색상을 직접 설정할 수 있습니다.

[title]자동 완성[/title]

[b]최대 자동 완성 개수:[/b] 이 임계값을 초과하는 자동 완성 항목은 잘려나가 오버헤드를 줄입니다.

[b]힌트 단어 표시:[/b] 활성화하면 힌트 단어가 괄호로 표시됩니다. 예:
[code]cat   (고양이)[/code]

[b]힌트 단어 가중치 사용:[/b] 활성화하면 힌트 단어를 입력할 때 우선순위가 높아집니다. 힌트 단어 유사도를 계산해야 하므로 성능 소모가 두 배가 됩니다.

[b]네임스페이스 자동 완성:[/b] 비활성화하면 [code]minecraft:apple[/code] 같은 항목이 [code]apple[/code]만 표시됩니다. 활성화하면 약간의 성능 계산이 필요합니다.
[title]동작[/title]

[b]더블 탭 매핑:[/b] 기호 입력을 돕기 위한 기능으로, 동일한 문자를 연속으로 빠르게 입력하면 변환됩니다. 기본 설정은 다음과 같습니다:
[code]" " : "\t"
"s" : "§"
"." : "~"
"," : "^"
"z" : "="
"n" : "!"
"a" : "@"
"q" : "{"
"p" : "}"
"w" : "["
"o" : "]"
"e" : "<"
"i" : ">"[/code]

[title]자동 저장[/title]

[b]자동 저장:[/b] 활성화하면 자동 저장이 허용됩니다.

[b]저장 간격:[/b] 자동 저장의 시간 간격입니다.

[title]문법[/title]

편집기에서 기본으로 사용하는 문법입니다.

[b]문법 경로:[/b] 문법 경로를 확인할 수 있습니다. 실행 시마다 디렉터리가 없으면 복사해 넣으려고 시도합니다.
[b]문법 추출:[/b] 문법이 없어졌거나 업데이트되지 않은 경우 수동으로 업데이트할 수 있습니다.
