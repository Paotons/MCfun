[title]설명[/title]

문법의 번역을 정의하는 데 사용됩니다.

[title]구성[/title]

[code]{
	"zh" : {...}
}[/code]

키는 언어 이름이고, 값은 언어 데이터입니다. 언어 데이터에는 두 가지 타입이 있습니다.

[title]언어 데이터 1[/title]

[code]{
	"apple" : "사과",
	"stone" : "돌"
}[/code]

첫 번째 언어 타입은 매핑 테이블입니다. 나타나는 키를 매핑된 값으로 교체합니다.
물론 번역 테이블이 매우 클 수 있으므로 [code]{"type" : "file", "file" : path}[/code] 로 대체할 수 있습니다.

[title]언어 데이터 2[/title]

[code]{
	"type" : "po_file",
	"file" : path
}[/code]

두 번째 언어 타입은 PO 파일입니다. PO 파일 하나를 선택하여 매핑합니다.
