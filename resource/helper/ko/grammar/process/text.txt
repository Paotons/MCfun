[title]설명[/title]

편집기에게 명령어의 요소가 어떻게 조합되는지 알려줍니다. 요소 [file grammar/element]문법>>요소[/file] 참고.

각 요소는 다음과 같은 새 멤버를 포함할 수 있습니다:
[b]id:[/b] 음이 아닌 정수. ID로, 비어 있으면 무작위로 값을 선택합니다. 중복되거나 음수이면 충돌할 수 있으므로 절대 중복하지 마세요.
[b]extends:[/b] 정수. 상속 대상. 마지막으로 성공적으로 실행된 요소의 ID입니다. -2는 임의, -1은 맨 처음 시작을 의미합니다. 비어 있으면 -2입니다.
[b]goto:[/b] 정수 또는 옵션의 경우 정수 배열. 성공적으로 실행되었을 때 이동할 ID이며, 옵션인 경우 추가 데이터에 따라 해당 위치로 이동합니다. 비워두면 바로 다음 단계를 실행합니다.
[b]is_end:[/b] 불리언. 종료 표시. 비어 있지 않고 실행에 성공하면 변경을 시도합니다. 종료 후에도 여전히 [code]false[/code] 이면 오류가 발생합니다.

또한 [code]{"type" : "file", "file" : "path"}[/code] 를 사용해 다른 파일의 내용을 데이터로 불러올 수 있습니다. 예: [code]"give" : {"type" : "file", "file" : "proces/give.json"}[/code]

[title]V1[/title]

[code] "give" : [{...}, {...}][/code]

이렇게 하면 [code]give[/code] 명령어가 정의되지만 힌트 단어는 없습니다.

[title]V2[/title]

[code]"give" : {
	"descriotion" : "플레이어에게 아이템 지급",
	"data" : [
		{...},
		{...}
	]
}
[/code]

[b]description:[/b] 설명. 힌트 단어.
[b]data:[/b] 데이터.

이렇게 하면 [code]give[/code] 명령어가 힌트 단어와 함께 정의됩니다.
