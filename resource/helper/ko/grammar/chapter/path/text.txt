[title]설명[/title]

목록 [file grammar/entry]문법>>목록[/file] 에서 경로 분류를 나타내는 데 사용됩니다.

또한 [code]{"type" : "file", "file" : "path"}[/code] 를 사용해 다른 파일의 내용을 데이터로 불러올 수 있습니다. 예: [code]"cat" : {"type" : "file", "file" : "entry/mob/cat.json"}[/code]

[title]V1[/title]

[code]playsound[/code] 는 다음과 같이 나타낼 수 있습니다.
[code]{
	"type" : "path",
	"data" : {
		"mob" : {
			"cat" : {
				"" : false,
				"hit" : false,
				"dead" : false
			}
		}
	}
}[/code]
이렇게 하면 [code]mob.cat mob.cat.hit mob.cat.deat[/code] 로 나타낼 수 있습니다.

[b]data:[/b] 무한 중첩을 나타내며, 계속 중첩할 수 있습니다. [code]false[/code] 는 자리 표시용입니다.

[title]V1[/title]

[code]playsound[/code] 는 다음과 같이 나타낼 수 있습니다.
[code]{
	"type" : "path",
	"data" : {
		"mob" : {
			"cat" : {
				"" : "고양이",
				"hit" : "고양이 피격",
				"dead" : "고양이 사망"
			}
		}
	}
}[/code]
이렇게 하면 [code]mob.cat mob.cat.hit mob.cat.deat[/code] 로 나타낼 수 있으며, 대응하는 힌트 단어가 함께 표시됩니다.

[b]data:[/b] 무한 중첩을 나타내며, 계속 중첩할 수 있습니다.
